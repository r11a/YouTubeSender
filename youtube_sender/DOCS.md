# YouTubeSender

## התחלה מהירה

1. צרו API Key בפרויקט Google Cloud שבו YouTube Data API v3 פעיל.
2. הזינו את המפתח בתצורת ה־App והפעילו אותו מחדש.
3. פתחו את Web UI, עברו ל**ערוצים** והוסיפו כתובת ערוץ או Channel ID.
4. לחצו **סנכרון עכשיו**.

## אנשי קשר מהטלפון

במכשירי Android ודפדפנים התומכים ב־Contact Picker ניתן לבחור אנשי קשר ישירות מספר הטלפונים, ללא יצירת קובץ. הדפדפן מציג חלון הרשאה והאפליקציה מקבלת רק את אנשי הקשר שנבחרו במפורש.

ב־iPhone, Safari/iOS אינו מספק כרגע Contact Picker לאפליקציות Web. לכן מוצג מסלול גיבוי דרך vCard (`.vcf`) מאפליקציית Contacts. אפשר גם לייבא CSV עם העמודות `name,phone,email,groups`.

הייבוא אינו מתקשר לענן Apple או Google ואינו מעלה את הקובץ לשירות חיצוני.

## שליחה

גרסה זו משתמשת בשליחה מונחית: היא פותחת WhatsApp, Email או Telegram עם הודעה מוכנה. לאחר השליחה מאשרים אותה ונשמרת מסירה היסטורית. ספקי API ישירים יכולים להתווסף תחת `server/providers`.

ל־WhatsApp אפשר להזין מספר ישראלי מקומי כגון `0501234567` או מספר בינלאומי כגון `+972501234567`. לפני פתיחת WhatsApp המערכת ממירה את המספר לפורמט הבינלאומי הנדרש, מציגה את שם הנמען והמספר ומבקשת אישור.

## AI

תבנית מקומית זמינה ללא מפתח. עבור OpenAI או Gemini הגדירו `ai_provider`, `ai_api_key` ו־`ai_model` במסך Configuration של ה־Add-on, או במסך **הגדרות** בתוך האפליקציה. בחירת `auto` משתמשת במודל החסכוני המומלץ לספק. המפתח נשמר בצד השרת בלבד. טקסט AI תמיד נשאר טיוטה ודורש אישור.

## מגבלות YouTube

API Key מחזיר מידע ציבורי. תגובות חדשות מזוהות בסנכרון לפי שינוי בכמות התגובות. YouTube אינו מספק אירוע אמין של “עוקב חדש” או זהות של כל מנוי; המערכת מציגה שינוי במספר המנויים כאשר הנתון ציבורי.
